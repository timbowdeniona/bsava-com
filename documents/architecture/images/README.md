# BSAVA API and Systems of Record replica diagram pack

Sources:

- `api_architecture.pdf`
- `BSAVA_Systems_of_Record_Justifications_Enhanced.pdf`

The source documents are the sole authority for diagram content, hierarchy, labels, connectors, and relationships. The established BSAVA Timberyard diagram system is used only for presentation styling. No systems, labels, connections, process steps, or architectural interpretations have been added.

## Visual system

- Montserrat-style geometric sans serif.
- Sand `#F5F2EF` background.
- Forest green `#214643` and dark green `#183330` structural surfaces.
- Viridian `#1A9B8C` accents and active connectors.
- Charcoal `#202020` text and white text on dark surfaces.
- Consistent flat fills, line icons, connector weights, and corner radii.
- 16:9 landscape canvas throughout.
